# Backend VeggieAI · 28/11/2026

- **Đã đưa lên nhánh `Khang`.** Khám phá, thực đơn, đổi món và chat dùng chung kho công thức đã duyệt. Cộng đồng hỗ trợ bài chữ, ảnh hoặc video, thích và bình luận. Công thức đính kèm tùy chọn và có quy trình duyệt riêng.
- **Dữ liệu chờ nhập và duyệt.** File SQL có 100 món, định lượng từ 76 nguyên liệu có mã USDA. Đã thử nhập lặp trên PostgreSQL. Công thức chưa được nấu thử hoặc duyệt trên production. [Hướng dẫn nhập kho](../BE/database/RECIPE_CATALOG.md)
- **Render hiện tại.** API phản hồi, PostgreSQL hoạt động, AI được cấu hình và danh mục còn 31 món. Endpoint sức khỏe báo lưu file thiếu lưu trữ bền vững. Cần cấu hình Cloudinary hoặc ổ đĩa bền vững trước khi dùng upload cộng đồng trên production.
- **Trước khi lên live.** Áp dụng migration dinh dưỡng và nhập kho trên staging, duyệt đủ món cho từng bữa, rồi thử tạo/đổi món, chat và upload với tài khoản user. Sau đó xác minh lại các luồng này trên Render. Bản trên `Khang` đã qua kiểm tra API local, gồm phân quyền công thức và gửi thích đồng thời.
