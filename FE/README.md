# 🖥️ VeggieAI Frontend Applications

This folder contains the client applications for VeggieAI:
1. **`web-admin/`**: Web Portal for **Admin** & **Moderators (Mod)** built with **React, TypeScript & Vite**.
   - Manage Members, Categories, and AI System Metrics.
   - Moderation Dashboard: Review and approve/reject community blogs and video recipes.
   - Review AI Flagged Content.

2. **`mobile-app/`**: Cross-platform Mobile Application for **End-Users** built with **Flutter (Dart)**.
   - AI Personalized Weekly Meal Planner.
   - Ingredient Recognition via Camera (Computer Vision).
   - AI Nutrition Chatbot (RAG).
   - Community Video Recipes, Blogs, and Vegan Store Location Map.
